# RS_1834 — люди и дворы

Поисковая база ревизской сказки 1834 года: 3002 человека, 276 дворов. Данные — проверенная версия на 8 октября 2026 года.

## Файлы
- index.html — интерфейс сайта; установки и сборки не требуется.
- data.json — снимок проверенных данных. Сохраняются стабильные Person ID и Family ID.

## Текущий статус
Репозиторий приватный. GitHub Pages не включён. Публичная публикация — только после отдельного решения владельца.

## Публикация на GitHub Pages (позже)
1. Репозиторий rs-1834 уже создан. Для бесплатного GitHub Pages он должен быть публичным; это изменение сейчас не выполняем.
2. Сохраните index.html и data.json в корне ветки main.
3. Откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main; folder: /(root); Save.
6. Ссылка сайта появится на той же странице после успешного развёртывания.

Адрес для аккаунта dashnak09: https://dashnak09.github.io/rs-1834/

## Обновление базы
Google Sheets остаётся рабочей базой. Сайт показывает опубликованный снимок, автоматической синхронизации нет. Для обновления замените data.json новой проверенной версией и сохраните commit. Код интерфейса менять не требуется, если сохранена структура данных. После завершения развёртывания перезагрузите страницу сайта; данные запрашиваются без сохранения в браузерном кеше.

## Работа со сведениями
Неизвестные данные остаются пустыми. Год рождения приблизителен. Совпадение фамилии не означает родство. Ссылки на Google Drive могут требовать доступа к сканам. Ссылки на сканы можно исключить из снимка: оставьте пустыми значения поля «Ссылка на скан» (индекс 19 в массивах people), сохранив номер JPG (индекс 18). Оригиналы на Drive и рабочая Google Sheets от этого не меняются. Не меняйте порядок колонок или стабильные ID.
